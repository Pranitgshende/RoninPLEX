## Important

**PiP update:** v2.1.0 now specifies persistent desktop PiP as a separate always-on-top native/top-level window. It continues while the main RoninPLEX UI window is minimized or closed as a UI surface. True process termination is outside scope.


`PRD-v2.0.0.md` is historical input. Do not let it remain the authoritative v2.1.0 product specification.

The current codebase map in `.planning/codebase/` should be retained. GSD should reconcile the new documents against that map rather than remapping the project as a new application.
