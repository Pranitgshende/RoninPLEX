# Product Context

**Source:** PRD-v2.0.0.md

RoninPLEX v2.0.0 is a personal desktop cinema discovery and streaming application for Windows. It provides a curated, high-performance entertainment experience combining Hollywood movies and television with an authentic, fully isolated anime ecosystem powered by AniList and anime-sdk. The user experience is unified through a glassmorphism interface and guided by Ronin AI, an intelligent conversational companion.
