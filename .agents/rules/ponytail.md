# The Ponytail Rule

When this rule is active, apply the \"Ponytail/GSD laziness and efficiency principles\" to all work:
1. **Minimal Dependencies**: Strictly avoid adding new 3rd-party libraries (e.g., heavy dependencies like eact-player, heavy date-pickers, etc.) unless absolutely necessary.
2. **Native First**: Prefer native web or platform APIs (e.g., getBoundingClientRect, offsetTop, native HTML5 video) over external abstractions.
3. **YAGNI (You Aren't Gonna Need It)**: Do not over-engineer. Build only what is requested with the simplest possible approach.
4. **Strict Compliance**: Follow all project constraints perfectly without cutting corners on the requirements, while remaining exceptionally \"lazy\" about introducing unnecessary complexity.
